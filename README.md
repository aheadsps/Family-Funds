# Семейные фонды

Семейный бюджет: каждый доход раскладывается по фондам в заданной очереди, траты списываются из фондов, есть подсказки «что делать сейчас» и «стоит ли покупать». Данные хранятся в Firebase и общие для всех участников семьи. Сайт работает как приложение на iPhone и без интернета.

## Запуск (один раз, около 30–40 минут)

### 1. GitHub: выложить сайт
1. Зарегистрируйтесь на https://github.com.
2. Нажмите **+** → **New repository**. Имя: `family-funds`, видимость **Public**, остальное не трогайте → **Create repository**.
3. На странице репозитория: **uploading an existing file** (или **Add file → Upload files**). Перетащите все файлы из распакованного архива, включая папку `icons` → **Commit changes**.
4. **Settings → Pages**. В «Branch» выберите `main` и `/ (root)` → **Save**. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/family-funds/`.

Код сайта будет виден всем, но в нём нет ничего секретного: данные семьи закрыты паролем и правилами доступа.

### 2. Firebase: база и вход
1. Откройте https://console.firebase.google.com, войдите через Google → **Create a project**. Имя: `family-funds`. Google Analytics можно выключить.
2. **Build → Authentication → Get started → Email/Password** → включите первый переключатель → **Save**.
   В **Authentication → Settings → Authorized domains** нажмите **Add domain** и добавьте `ВАШ-ЛОГИН.github.io`.
3. **Build → Firestore Database → Create database**. Location: `eur3 (europe)`. Режим: **production** → **Create**.
4. Там же вкладка **Rules**: сотрите всё и вставьте содержимое файла `firestore.rules` → **Publish**.
5. Шестерёнка → **Project settings → General → Your apps** → значок **</>** (Web). Название `site`, галочку Hosting не ставить → **Register app**. Появится блок `const firebaseConfig = {...}`.

### 3. Подключить сайт к базе
Откройте в GitHub файл `firebase-config.js` → значок карандаша → замените пустые строки значениями из `firebaseConfig` → **Commit changes**. Через минуту обновите сайт.

### 4. Начать пользоваться
1. Откройте сайт, нажмите **Зарегистрироваться**.
2. Выберите **Создать семейный бюджет** с галочкой переноса фондов из Claude.
3. Меню **☰ → Семья** покажет код приглашения. Второй человек регистрируется на сайте, выбирает **Присоединиться по коду** и вводит его.

### 5. Иконка на iPhone
Откройте сайт в **Safari** → **Поделиться** → **На экран «Домой»**. Внутри иконки нужно войти ещё раз: у неё отдельное хранилище от Safari.

## Если что-то не работает
- Белый экран «Сайт ещё не подключён к базе»: не заполнен `firebase-config.js`.
- «Нет доступа» при создании бюджета: не опубликованы правила из `firestore.rules`.
- Консоль Firebase пишет, что сервис недоступен в вашей стране: создайте проект через VPN. Самому сайту VPN для работы не нужен, проверьте с телефона.

## Файлы
- `index.html`, `app.js` — интерфейс и расчёты
- `fb.js` — работа с Firebase
- `firebase-config.js` — ключи проекта
- `firestore.rules` — правила доступа к данным
- `seed.js` — фонды и записи из версии в Claude, используются один раз
- `sw.js`, `manifest.webmanifest`, `icons/` — режим приложения и работа без сети
